# Boletim da Turma

Projeto da Aula 36 do curso Técnico em Informática para Internet do SENAI.
O boletim recebe o nome do aluno e duas notas, calcula a média e exibe
o resultado em uma tabela.

## Regras de avaliação

| Média | Situação |
| --- | --- |
| 7 ou mais | Aprovado |
| De 5 até menos de 7 | Recuperação |
| Menos de 5 | Reprovado |

O formulário aceita notas de 0 a 10, com vírgula ou ponto decimal.

## Como executar

1. Baixe ou clone o repositório.
2. Abra o arquivo `index.html` no navegador.
3. Preencha o nome e as duas notas e clique em **Adicionar**.

## Tecnologias

- HTML5
- Bootstrap 5.3.8
- JavaScript
